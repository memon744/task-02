# 💜 Maira Memon — Responsive Portfolio Website

A modern, animated, and fully responsive personal portfolio website built with **HTML**, **CSS**, and **JavaScript**.

---

## 🌟 Features

- ⌨️ **Typing Effect** — animated text cycling through roles in the hero section
- 🎨 **Animated Gradient Background** — smooth color-shifting hero section
- 📦 **AOS Animations** — scroll-triggered fade and zoom effects on project cards
- 📱 **Fully Responsive** — mobile hamburger menu, flexible layouts for all screen sizes
- 🧊 **Glassmorphism & Card UI** — modern project cards with hover effects
- 📬 **Contact Form** — styled form with smooth interactions
- 🔝 **Sticky Navbar** — gradient navbar with smooth scroll links

---

## 🗂️ Sections

| Section | Description |
|---------|-------------|
| **Navbar** | Responsive navigation with hamburger toggle for mobile |
| **Hero** | Animated gradient background with typing effect |
| **About** | Bio with profile image in a two-column layout |
| **Projects** | AOS-animated cards showcasing featured work |
| **Contact** | Contact form with name, email, and message fields |

## 📱 Responsive Breakpoints

| Screen Size | Behavior |
|-------------|----------|
| Desktop (> 768px) | Full navbar, two-column about section, cards in a row |
| Tablet (≤ 768px) | Stacked about section, vertical cards |
| Mobile (≤ 600px) | Hamburger menu, single-column layout |
